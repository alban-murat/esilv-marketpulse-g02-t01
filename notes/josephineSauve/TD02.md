# TD02 – Python avec CSV et JSON

Objectif : MarketPulse charge les deux fichiers, sépare les deux séries et affiche un résumé réutilisable.

## Ce que fait le code (`src/main.py`)

| Élément | Rôle |
|---|---|
| `load_instruments()` | lit `instruments.json` → dictionnaire |
| `load_prices()` | lit `prices.csv` → liste de dictionnaires (une ligne = un dict) |
| `filter_prices(prices, ticker)` | garde uniquement les lignes d'un ticker |
| `get_first_close(prices)` | premier `close`, converti en `float` |
| `get_last_close(prices)` | dernier `close`, converti en `float` |
| `display_market_summary(asset, prices, show_currency=True)` | affiche le résumé d'une série |
| `main()` | charger → filtrer → afficher |

## Points clés

- Les valeurs CSV sont du **texte** : `type(prices[0]["close"])` → `str`. On convertit avec `float()` avant tout calcul ou formatage numérique.
- Même opération + données différentes = **une fonction réutilisable** : `display_market_summary` sert pour l'instrument et pour le benchmark (sans devise pour le benchmark).

| Série | First close | Last close |
|---|---|---|
| AAPL | 250.00 | 266.20 |
| SP500 | 6600.00 | 6742.00 |

## Sortie obtenue

```text
=== MarketPulse ===

Market configuration
Period   : 1 month
Interval : Daily

Instrument
AAPL - Apple Inc.
Observations : 21
First close  : 250.00 USD
Last close   : 266.20 USD

Benchmark
SP500 - S&P 500
Observations : 21
First close  : 6600.00
Last close   : 6742.00
```

## Erreurs fréquentes

| Erreur | À vérifier |
|---|---|
| `IndexError` | la liste filtrée est vide |
| `KeyError` | orthographe / majuscules des clés |
| `ValueError` dans `float()` | la valeur n'est pas du texte numérique |
| `FileNotFoundError` | lancer depuis la racine du projet |
| `TypeError` avec `+` / `-` | calcul sur une chaîne : convertir avec `float()` |
