# TD01 – Linux et découverte des données

## 1. Se repérer dans le terminal

| Commande | Rôle |
|---|---|
| `pwd` | afficher le dossier courant |
| `ls` / `ls -la` | lister les fichiers (format long + fichiers cachés) |
| `cd data` / `cd ..` / `cd ../..` / `cd ~` | changer de dossier |

À la racine du projet, on trouve notamment : `README.md`, `config`, `data`, `evidence`, `labs`, `src`.

```bash
cd data/sample
pwd
ls          # instruments.json  prices.csv  ...
cd ../..
pwd         # retour à la racine
```

## 2. Lire les fichiers de données

### JSON – `data/sample/instruments.json`

```bash
cat data/sample/instruments.json
```

| Rôle | ticker | name | currency | market |
|---|---|---|---|---|
| `instrument` | AAPL | Apple Inc. | USD | NASDAQ |
| `benchmark` | SP500 | S&P 500 | USD | US |

- Instrument : **AAPL – Apple Inc.**
- Benchmark : **SP500 – S&P 500**
- Les noms et tickers sont stockés dans les clés `name` et `ticker` de chaque bloc.

### CSV – `data/sample/prices.csv`

```bash
head data/sample/prices.csv
```

En-tête : `date,ticker,open,high,low,close,volume`

### Rechercher un mot

```bash
grep AAPL data/sample/prices.csv     # 21 lignes
grep SP500 data/sample/prices.csv    # 21 lignes
```

Le même fichier CSV contient les **deux séries** (instrument et benchmark) : 42 observations + 1 ligne d'en-tête.
