# TD04 – Nouvelle fonctionnalité : afficher les dates

Fonctionnalité : afficher la première et la dernière date d'observation pour l'instrument **et** pour le benchmark. Elle s'appuie sur les helpers du TD02. Pas de calcul de rendements.

## Code ajouté dans `src/main.py`

```python
def get_first_date(prices):
    return prices[0]["date"]

def get_last_date(prices):
    return prices[-1]["date"]
```

Intégré dans `display_market_summary`, entre `Observations` et `First close` :

```python
print(f"First date   : {get_first_date(prices)}")
print(f"Last date    : {get_last_date(prices)}")
```

Comme `display_market_summary` est réutilisée pour les deux séries, l'instrument et le benchmark affichent les dates sans dupliquer de code.
