# TD03 – Git en local

Le travail commité est celui du TD02 (résumé de marché réutilisable). Pas de changement artificiel.

## Cycle utilisé

```bash
git config user.name    # vérifier mon identité Git
git config user.email
git status              # voir les fichiers modifiés
git diff                # relire les changements avant de les ajouter
git add src/main.py     # préparer (staging) uniquement ce qui est voulu
git diff --staged       # vérifier ce qui part dans le commit
python src/main.py      # MarketPulse fonctionne toujours
git commit -m "refactor: reuse market summary display"
git add TEAM.md         # TEAM.md (TD01) dans un commit séparé
git commit -m "docs: add TEAM.md for team G02-T01"
git log --oneline       # vérifier l'historique
git show --stat HEAD    # inspecter le dernier commit
```

## À retenir

| Notion | Signification |
|---|---|
| working directory | fichiers modifiés, pas encore préparés |
| staging area | ce qui sera dans le prochain commit (`git add`) |
| commit | instantané enregistré dans l'historique, avec un message clair |
| `git diff` | changements non préparés |
| `git diff --staged` | changements préparés |

Enregistrer un fichier dans l'éditeur ne crée pas de commit : il faut `git add` puis `git commit`.
